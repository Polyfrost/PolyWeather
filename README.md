# PolyWeather

[![Modrinth downloads](https://img.shields.io/modrinth/dt/r8Cr8YRg?style=flat&logo=modrinth&label=Modrinth&color=1bd96a)](https://modrinth.com/mod/polyweather)
[![CurseForge downloads](https://img.shields.io/curseforge/dt/1148002?style=flat&logo=curseforge&label=CurseForge&color=f16436)](https://www.curseforge.com/minecraft/mc-mods/polyweather)

PolyWeather swaps the weather you see for one you pick. It's purely visual, the server's weather stays what it is.

- Clear, rain, storm or snow in any biome (yes, snow in the desert)
- Intensity sliders for rain, snow and thunder
- Sky, clouds and fog tint to match the weather you picked
- Rain sounds and ground splashes follow along
- Use the real weather where you live (restart the game after turning this on)

## Supported versions

- Minecraft 1.8.9 on Ornithe.
- Minecraft 1.21.1-26.3 on Fabric.

PolyWeather needs [OneConfig](https://modrinth.com/mod/oneconfig) and Fabric Language Kotlin.
